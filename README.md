# IMZ Display

A full-stack internal dashboard designed to streamline the display and management of insurance-related information. The application provides an intuitive interface for viewing, organizing, and updating records while integrating backend services for efficient data retrieval and processing.

## Features

- Secure full-stack web application
- Interactive dashboard for managing records
- Backend API for retrieving and updating data
- SQL database integration
- Responsive user interface
- Modular architecture for easy maintenance

## Tech Stack

## Getting Started

### Prerequisites

- Visual Studio
- .NET SDK
- SQL Server

### Installation

```bash
git clone https://github.com/arpansen-cloud/IMZ-Display.git
```

Configure the SQL Server connection string inside the application settings before running.

Run the project using Visual Studio or:

```bash
dotnet run
```
